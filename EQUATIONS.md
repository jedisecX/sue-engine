# Equation talk

`/eq` lists the library. `/eq uncertainty` or chat `what is ħ`.

Domains: psychometrics (z, Pearson r, Cronbach α, 2PL IRT, Spearman g, Shannon H), quantum (Schrödinger, Born, Kennard, Planck, de Broglie, [x,p]=iħ), physics (Newton, E=mc², kinetic, waves, Clausius, Coulomb, Faraday).

Talk stores `kind=eq` traces so a later turn can retrieve the same form.
Bridges name shared symbols only. They are not new laws.
